## Muusikatunnid.ee

**Muusikatunnid.ee** is the project I spend most of my development time on.

It started as a music education website and has gradually grown into a larger Laravel application with structured learning materials, interactive exercises and browser-based music tools.

Some of the things I've been working on:

* interactive piano and music exercises
* music notation in the browser
* quizzes and digital learning materials
* user roles and permissions
* media and content management
* automated tests and static analysis

**Stack:**
`Laravel 12` · `PHP` · `JavaScript` · `Alpine.js` · `Tailwind CSS` · `Vite` · `Filament` · `Tone.js` · `VexFlow`
