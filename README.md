## Featured Project

### 🎵 Muusikatunnid.ee

A digital platform for music education and interactive learning.

The project combines traditional educational content with modern web technologies and browser-based music tools.

**Core stack**

`Laravel 12` · `PHP 8.2+` · `JavaScript` · `Alpine.js` · `Tailwind CSS` · `Vite` · `Filament`

**Development practices**

`PHPUnit` · `PHPStan / Larastan` · `Laravel Pint` · `Git`

**Interactive technologies**

`Tone.js` · `VexFlow`

The platform includes:

* structured digital learning materials
* interactive exercises and quizzes
* browser-based piano and music-learning tools
* music notation and audio functionality
* user and permission management
* media and learning-content management
* automated testing and static analysis
